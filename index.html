🦠 STI-OPOLY 🎲

10-player online nursing game

Join the game

🖥️ Open host display (spectator screen)

One person creates a room. Share its code with up to 9 other players. Each player uses their own browser.

Rules

Each player begins with $1,500 and one Get Out of Detention Free card. Buy unowned properties, pay rent, and answer questions on Chance and Community Care spaces. Incorrect answers return ALL your properties to the bank. Trades require acceptance. No houses, auctions, or mortgages. The host can end the game to display net-worth rankings.
